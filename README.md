# Japanese Megane

Japanese reading annotations in the browser and terminal. Kanji receives hiragana;
recognized katakana receives an original spelling or a concise English meaning.

The offline katakana dataset is derived from JMdict, the property of James William
Breen and the Electronic Dictionary Research and Development Group (EDRDG), and
used in conformance with the Group's licence. The derived data is CC BY-SA 4.0.
See [dictionary sources and licensing](docs/dictionary-sources.md) and
[dictionary maintenance](docs/loanwords.md).

## Pronunciation

Click a word, or select a passage and click inside the selection, to hear Japanese.
Kanji uses its annotated kana; English loanword glosses are never spoken.

Audio is generated by Microsoft Edge Read Aloud's **ja-JP-NanamiNeural** voice via
the server and played as MP3, not through the operating system's speech engine.
An internet connection is required. Only text requested for pronunciation is sent
to Microsoft's speech service; dictionary annotation remains local. Audio is
cached temporarily in server memory, not written to disk. A request may contain
up to 2,000 characters; clicking another word stops the previous playback.

This uses the unofficial `msedge-tts` client without an API key. The upstream
service may change or become unavailable; there is deliberately no silent fallback
to system speech. A production deployment should use a supported, licensed speech
service such as Azure AI Speech.

## React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

```js
  },

```
